## 1. Какая команда оказалась самой непонятной до практики?
**Ответ:** git revert. Думал, что проще git reset, но revert безопаснее — он не удаляет историю, а создает новый коммит отмены.

## 2. Почему важно настраивать user.name/email перед коммитами?
**Ответ:** Чтобы знать, кто автор изменений. В командной работе это критично для поиска виновных в багах и статистики вклада.

## 3. В каком случае git revert безопаснее, чем git reset?
**Ответ:** Когда коммит уже на GitHub и другие могли его скачать. reset перепишет историю и вызовет конфликты, revert просто откатит изменения новым коммитом.

## 4. Как .gitignore мог бы спасти проект от утечки данных?
**Ответ:** Не дал бы закоммитить .env с паролями или логи с данными пользователей. В нашем проекте мы добавили .env и *.log в .gitignore.
